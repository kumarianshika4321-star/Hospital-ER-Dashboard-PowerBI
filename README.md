This project provides an interactive Power BI dashboard for a hospital's Emergency Room. It analyzes key performance indicators (KPIs) such as patient volume, average wait time, patient satisfaction, and admission rates. The dashboard provides insights into patient demographics (age, gender, race), referral departments, and peak hours, enabling data-driven decisions to improve ER efficiency and patient care.

**Key Features:**
- 📊 Executive Summary with key KPIs
- 👥 Patient demographic breakdowns
- ⏰ Peak hour and day-of-week analysis
- 📈 Department referral patterns
- 🏥 Admission status analysis
- 🔍 Drill-through capabilities for detailed analysis

**Dataset:** Synthetic patient data (1000+ records) including admission details, wait times, satisfaction scores, and demographic information..
